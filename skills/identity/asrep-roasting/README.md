# AS-REP Roasting

Investigate authentication requests involving accounts without Kerberos preauthentication.

**Input:** Authentication-service events, preauthentication fields, requester source and account settings.

**Result:** Preauthentication exposure and request/use correlation.

Download [asrep-roasting.zip](../../../dist/chatgpt/asrep-roasting.zip) and import one package in a compatible Skills interface. Name the skill and attach relevant evidence. The package includes the workflow, a focused analysis guide, reviewed primary-source links and optional connection guidance. It contains no classroom/demo payloads, API keys or active service connection.

**Validation:** Source and package review; no claim of end-to-end model or SIEM effectiveness. Configure integrations separately and validate any generated queries/configuration against your actual backend. See [analysis guidance](references/analysis.md) for meaningful acceptance criteria and limitations.
