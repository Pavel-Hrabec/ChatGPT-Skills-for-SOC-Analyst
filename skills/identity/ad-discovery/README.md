# Active Directory Discovery

**Skill ID:** `ad-discovery`

## Purpose

Analyze directory enumeration evidence from LDAP, native Windows utilities, and AD assessment tools, including queried objects, scope, identity, and surrounding activity.

## Use

Import the matching `ad-discovery.zip` from `dist/chatgpt/`. In a new chat, name the skill and attach the relevant alert, event export, scan output, or directory artifact. A short question is sufficient; the skill supplies the investigation workflow.

This skill works from supplied evidence and authorized connections available in the chat. It does not grant access to an endpoint, directory, network scanner, SIEM, or XDR platform.
