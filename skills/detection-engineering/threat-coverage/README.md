# Threat Coverage

Assess defensive coverage against a specific reported threat sequence.

**Input:** Cited campaign behavior, environment exposure, telemetry and validated detection inventory.

**Result:** Threat-specific coverage map with evidence strength and action priorities.

Download [threat-coverage.zip](../../../dist/chatgpt/threat-coverage.zip) and import one package in a compatible Skills interface. Name the skill and attach relevant evidence. The package includes the workflow, a focused analysis guide, reviewed primary-source links and optional connection guidance. It contains no classroom/demo payloads, API keys or active service connection.

**Validation:** Source and package review; no claim of end-to-end model or SIEM effectiveness. Configure integrations separately and validate any generated queries/configuration against your actual backend. See [analysis guidance](references/analysis.md) for meaningful acceptance criteria and limitations.
