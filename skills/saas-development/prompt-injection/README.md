# Prompt Injection

Investigate untrusted content that attempts to redirect an AI security workflow.

**Input:** Original prompt/data boundary, retrieved content, tool-call trace and observed output/action evidence.

**Result:** Trust-boundary analysis, observed impact and reproducible defensive tests.

Download [prompt-injection.zip](../../../dist/chatgpt/prompt-injection.zip) and import one package in a compatible Skills interface. Name the skill and attach relevant evidence. The package includes the workflow, a focused analysis guide, reviewed primary-source links and optional connection guidance. It contains no classroom/demo payloads, API keys or active service connection.

**Validation:** Source and package review; no claim of end-to-end model or SIEM effectiveness. Configure integrations separately and validate any generated queries/configuration against your actual backend. See [analysis guidance](references/analysis.md) for meaningful acceptance criteria and limitations.
