# Intel Dedup

Deduplicate intelligence while preserving distinct observations and source lineage.

**Input:** Feed exports, provider IDs, typed indicator values, timestamps and original references.

**Result:** Canonical entity/observation merge plan and loss analysis.

Download [intel-dedup.zip](../../../dist/chatgpt/intel-dedup.zip) and import one package in a compatible Skills interface. Name the skill and attach relevant evidence. The package includes the workflow, a focused analysis guide, reviewed primary-source links and optional connection guidance. It contains no classroom/demo payloads, API keys or active service connection.

**Validation:** Source and package review; no claim of end-to-end model or SIEM effectiveness. Configure integrations separately and validate any generated queries/configuration against your actual backend. See [analysis guidance](references/analysis.md) for meaningful acceptance criteria and limitations.
