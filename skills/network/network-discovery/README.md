# Network Recon and SMB Discovery

**Skill ID:** `network-discovery`

## Purpose

Analyze authorized scan scope and results, scanning alerts, remote host and service discovery, and SMB share enumeration from supplied evidence.

## Use

Import the matching `network-discovery.zip` from `dist/chatgpt/`. In a new chat, name the skill and attach the relevant alert, event export, scan output, or directory artifact. A short question is sufficient; the skill supplies the investigation workflow.

This skill works from supplied evidence and authorized connections available in the chat. It does not grant access to an endpoint, directory, network scanner, SIEM, or XDR platform.
