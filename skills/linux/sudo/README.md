# Sudo

Investigate privilege changes through sudo.

**Input:** Sudo logs, invoking user, target user, command/arguments, terminal and policy evidence.

**Result:** Privilege-use timeline and policy-context assessment.

Download [sudo.zip](../../../dist/chatgpt/sudo.zip) and import one package in a compatible Skills interface. Name the skill and attach relevant evidence. The package includes the workflow, a focused analysis guide, reviewed primary-source links and optional connection guidance. It contains no classroom/demo payloads, API keys or active service connection.

**Validation:** Source and package review; no claim of end-to-end model or SIEM effectiveness. Configure integrations separately and validate any generated queries/configuration against your actual backend.
