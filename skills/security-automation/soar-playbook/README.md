# SOAR Playbook

Design a reviewable automation playbook for a defined security workflow.

**Input:** Trigger schema, available actions, permissions, decision criteria and platform constraints.

**Result:** Playbook specification or code, action contracts and failure/recovery tests.

Download [soar-playbook.zip](../../../dist/chatgpt/soar-playbook.zip) and import one package in a compatible Skills interface. Name the skill and attach relevant evidence. The package includes the workflow, a focused analysis guide, reviewed primary-source links and optional connection guidance. It contains no classroom/demo payloads, API keys or active service connection.

**Validation:** Source and package review; no claim of end-to-end model or SIEM effectiveness. Configure integrations separately and validate any generated queries/configuration against your actual backend. See [analysis guidance](references/analysis.md) for meaningful acceptance criteria and limitations.
