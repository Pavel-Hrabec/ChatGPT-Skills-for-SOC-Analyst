# AWS Lambda

Investigate suspicious Lambda code, configuration and invocation activity.

**Input:** Function version/configuration changes, CloudTrail, execution logs and role/resource metadata.

**Result:** Function-version timeline and confirmed execution/resource effects.

Download [aws-lambda.zip](../../../dist/chatgpt/aws-lambda.zip) and import one package in a compatible Skills interface. Name the skill and attach relevant evidence. The package includes the workflow, a focused analysis guide, reviewed primary-source links and optional connection guidance. It contains no classroom/demo payloads, API keys or active service connection.

**Validation:** Source and package review; no claim of end-to-end model or SIEM effectiveness. Configure integrations separately and validate any generated queries/configuration against your actual backend. See [analysis guidance](references/analysis.md) for meaningful acceptance criteria and limitations.
