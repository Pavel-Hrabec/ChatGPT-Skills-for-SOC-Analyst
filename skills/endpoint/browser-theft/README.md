# Browser Theft

Investigate access to browser credential and session stores.

**Input:** File-access or endpoint alerts, browser profile paths, caller process, archive/network evidence.

**Result:** Profile exposure scope and evidence of subsequent credential/session misuse.

Download [browser-theft.zip](../../../dist/chatgpt/browser-theft.zip) and import one package in a compatible Skills interface. Name the skill and attach relevant evidence. The package includes the workflow, a focused analysis guide, reviewed primary-source links and optional connection guidance. It contains no classroom/demo payloads, API keys or active service connection.

**Validation:** Source and package review; no claim of end-to-end model or SIEM effectiveness. Configure integrations separately and validate any generated queries/configuration against your actual backend. See [analysis guidance](references/analysis.md) for meaningful acceptance criteria and limitations.
