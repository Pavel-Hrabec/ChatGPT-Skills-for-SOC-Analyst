Investigate permanent WMI event subscriptions and their execution evidence.

**Result:** Subscription relationship map, trigger behavior and execution evidence.

Download [wmi-persistence.zip](../../../dist/chatgpt/wmi-persistence.zip) and import one package in a compatible Skills interface. Name the skill and attach relevant evidence. **Validation:** Source and package review; no claim of end-to-end model or SIEM effectiveness.
