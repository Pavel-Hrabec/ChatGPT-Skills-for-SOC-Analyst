# Defender Tampering

Investigate changes that impair Microsoft Defender or its visibility.

**Input:** Configuration audit events, exclusion changes, service state, tamper-protection results and actor context.

**Result:** Protection-impact assessment with confirmed and attempted changes separated.

Download [defender-tampering.zip](../../../dist/chatgpt/defender-tampering.zip) and import one package in a compatible Skills interface. Name the skill and attach relevant evidence. The package includes the workflow, a focused analysis guide, reviewed primary-source links and optional connection guidance. It contains no classroom/demo payloads, API keys or active service connection.

**Validation:** Source and package review; no claim of end-to-end model or SIEM effectiveness. Configure integrations separately and validate any generated queries/configuration against your actual backend. See [analysis guidance](references/analysis.md) for meaningful acceptance criteria and limitations.
