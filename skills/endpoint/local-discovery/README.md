# Local System Discovery

**Skill ID:** `local-discovery`

## Purpose

Analyze endpoint evidence showing commands or processes gathering local identity, system, network, process, service, session, or privilege information.

## Use

Import the matching `local-discovery.zip` from `dist/chatgpt/`. In a new chat, name the skill and attach the relevant alert, event export, scan output, or directory artifact. A short question is sufficient; the skill supplies the investigation workflow.

This skill works from supplied evidence and authorized connections available in the chat. It does not grant access to an endpoint, directory, network scanner, SIEM, or XDR platform.
