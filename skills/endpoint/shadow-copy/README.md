# Shadow Copies

Investigate deletion or disruption of backups and shadow copies.

**Input:** Process events, backup product logs, shadow-copy inventory and administrator sessions.

**Result:** Recovery-impact timeline and confirmed backup exposure.

Download [shadow-copy.zip](../../../dist/chatgpt/shadow-copy.zip) and import one package in a compatible Skills interface. Name the skill and attach relevant evidence. The package includes the workflow, a focused analysis guide, reviewed primary-source links and optional connection guidance. It contains no classroom/demo payloads, API keys or active service connection.

**Validation:** Source and package review; no claim of end-to-end model or SIEM effectiveness. Configure integrations separately and validate any generated queries/configuration against your actual backend.
